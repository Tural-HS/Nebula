# Nebula v0.2.2

v0.2.1-dən sonrakı buraxılış: giriş axınında (başlıq, ana səhifə, cədvəl, tapşırıq paneli) əlçatanlıq və interfeys
düzəlişləri. v0.2.0-dan birbaşa yeniləmədə v0.2.1-in workspace SMTP ayarları da gəlir (`v0.2.1.md`).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.2.2@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.2.2@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.2.2@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.2.2@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Kontrast:** qaranlıq mövzuda ikinci dərəcəli mətnlər, işıqlı mövzuda "Təyin olunmayıb" və sıfır sayğaclar, input
  sərhədləri və placeholder-lər WCAG həddinə çatdırıldı.
- **Klaviatura:** fokus hər yerdə görünür; telefon və planşetdə tapşırıq paneli fokusu götürür, Tab paneldən çıxmır,
  bağlananda fokus sətrə qayıdır; Esc açıq dialoqu bağlayır, paneli yox.
- **Tapşırıq paneli:** yüklənmə, xəta və "tapılmadı" hallarında da bağla düyməsi və "Yenidən cəhd et"; silmə tapşırığın
  açarını adlandıran dialoqla təsdiqlənir.
- **Telefon:** sorğular, dil, tema və çıxış hesab menyusundadır (avatar); səhifə adı ayrıca sətirdə; görünüş düymələri
  ikonlarla, toolbar 320 px-də də bir sətirdə.
- **Ekran oxuyucu:** siqnallar, son tarix, avatar və redaktə xanaları düzgün adlanır; şərh tabları ox düymələri ilə.
- **Mətnlər:** xəta mesajları nə etməli olduğunu deyir; boş siyahıda növbəti addım (filtrləri təmizlə və ya yeni
  tapşırıq); vahid terminlər ("tapşırıq", "Gecikən"); xəta bildirişləri bağlanana qədər qalır.
- **Tipoqrafiya və hərəkət:** 10–11 px mətnlər rem-dədir (brauzer şrift ölçüsünə uyğunlaşır); spinner
  "hərəkəti azalt" ayarına tabedir.
