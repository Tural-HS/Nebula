# Nebula v0.3.4

v0.3.3-dən sonrakı buraxılış: sütun filtrləri və cədvəl sıxlığı (ADR-0048).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.4@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.4@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.4@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.4@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Sütun filtrləri:** hər sahə sütununun başlığında ▾ menyu — Artan/Azalan sıralama; mətndə "içində" axtarış
  (hərf variantları nəzərə alınmadan); rəqəm və tarix aralığı (Başlanğıc/Son); seçim və bəli/xeyr. Çiplər operatoru
  sözlə göstərir (`Qalıq: ≥ 900`, `Telefon: içində "5541"`); filtrlər görünüşdə saxlanılır.
- **API:** `?field.<key>=~mətn` (içində) və `?field.<key>=min..max` (aralıq); operatorsuz dəyər əvvəlki kimi dəqiqdir.
- **Sıxlıq:** toolbar-da "Sıx" (24 px sətir, 12 px şrift), seçim brauzerdə yadda qalır. Normal: 28 px, 13 px,
  daha dar sütunlar və boşluqlar.

## Miqrasiyalar

Yeni miqrasiya yoxdur.

## Yeniləmə (v0.3.x → v0.3.4)

`deploy.sh` yeni digest-lərlə (`--verify`). `.env`-də dəyişiklik lazım deyil. v0.3.3-ə qayıtdıqda operatorlu
filtrləri olan saxlanmış görünüşlər boş siyahı (rəqəm/tarixdə xəta) göstərə bilər.

## Məlum məhdudiyyətlər

- "Boşdur" operatoru və seçim sahələrində çoxlu seçim hələ yoxdur.
- Caddy `x/net` istisnası 2026-12-31-ə qədər (ADR-0018).
