# Nebula v0.3.9

v0.3.8-dən sonrakı kiçik buraxılış: cədvəlin cəm sətrində sətir sayı.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.9@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.9@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.9@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.9@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- Cədvəlin alt sətri **"Cəmi: N"** göstərir: filtrə uyğun bütün tapşırıqların sayı (yüklənməmiş səhifələr də
  daxil). Rəqəm sütunu olmayan cədvəllərdə də görünür. `GET …/items/sums` cavabına `count` əlavə olundu; `fields`
  artıq məcburi deyil.

## Miqrasiyalar

Yoxdur.

## Yeniləmə (v0.3.8 → v0.3.9)

`deploy.sh` yeni digest-lərlə (`--verify`). `.env`-də dəyişiklik lazım deyil. Geri qayıtmaq: v0.3.8 image-ləri.
