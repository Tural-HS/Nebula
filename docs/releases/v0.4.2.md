# Nebula v0.4.2

Çat kanalı üçün yalnız vacib bildirişlər və səhər xülasəsinin dəqiqəsi (ADR-0059).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.4.2@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.4.2@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.4.2@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.4.2@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- Webhook abunəsində **`item.status_changed`**: yalnız statusu dəyişən redaktələr kanala gedir (sahə
  redaktələri getmir). Status "done" kateqoriyasına keçəndə mesaj ✅ ilə başlayır.
- Səhər xülasəsinin vaxtı **dəqiqə ilə** (məs. 09:30): Ayarlar → Ümumi, yarım saat addımı. Ad günü
  xatırlatmaları da həmin vaxtda gəlir.

## Miqrasiyalar

- `00042_workspace_digest_minute`: `workspaces.overdue_digest_minute` (sabit default, millisaniyəlik kilid).

## Yeniləmə (v0.4.1 → v0.4.2)

`deploy.sh` yeni digest-lərlə (`--verify`). `.env`-də dəyişiklik lazım deyil. Geri qayıtmaq: v0.4.1 image-ləri
(köhnə image sütunu oxumur; `item.status_changed` abunəsi olan webhook köhnə image-də heç nə almaz).
