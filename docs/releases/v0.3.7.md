# Nebula v0.3.7

## Nə yenidir

- **Canlı sütun filtri:** sütun menyusunda mətn, rəqəm və ya tarix yazdıqca (0,3 s fasilədən sonra) cədvəl
  süzülür; seçimlərdə hər işarə dərhal tətbiq olunur. Enter və ya "Tətbiq et" menyunu bağlayır.
- Yeni filtrdə siyahı spinner-ə keçmir: cavab gələnə qədər əvvəlki sətirlər qalır (başqa layihənin sətirləri heç
  vaxt göstərilmir).
- Sütun filtri heç nə tapmasa cədvəlin başlığı qalır, altında "uyğun tapşırıq yoxdur" və "Filtrləri təmizlə";
  menyu açıq qalır, mətni düzəltmək olur.
