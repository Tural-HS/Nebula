# Nebula v0.3.7

v0.3.6-dan sonrakı kiçik buraxılış: cədvəlin sütun filtri yazdıqca işləyir.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.7@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.7@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.7@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.7@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Canlı sütun filtri:** sütun menyusunda mətn, rəqəm və ya tarix yazdıqca (0,3 s fasilədən sonra) cədvəl
  süzülür; seçimlərdə hər işarə dərhal tətbiq olunur. Enter və ya "Tətbiq et" menyunu bağlayır.
- Yeni filtrdə siyahı spinner-ə keçmir: cavab gələnə qədər əvvəlki sətirlər qalır (başqa layihənin sətirləri heç
  vaxt göstərilmir).
- Sütun filtri heç nə tapmasa cədvəlin başlığı qalır, altında "uyğun tapşırıq yoxdur" və "Filtrləri təmizlə";
  menyu açıq qalır, mətni düzəltmək olur.

## Miqrasiyalar

Yoxdur.

## Yeniləmə (v0.3.6 → v0.3.7)

`deploy.sh` yeni digest-lərlə (`--verify`). `.env`-də dəyişiklik lazım deyil. Geri qayıtmaq: v0.3.6 image-ləri.
