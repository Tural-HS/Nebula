# Nebula v0.4.4

Kiçik buraxılış: cədvəlin "Status" sütununda filtr menyusu.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.4.4@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.4.4@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.4.4@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.4.4@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.
