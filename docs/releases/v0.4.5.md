# Nebula v0.4.5

Layihə qaydaları: tamamlanma sahələri və gecikmə rəngi (ADR-0061).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.4.5@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.4.5@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.4.5@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.4.5@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- Layihə ayarlarında **"Tamamlanma və gecikmə qaydaları"**:
  - **Tamamlanma sahələri**: hamısı işarəli olmadan tapşırığı "Tamamlandı" etmək olmur, hamısı işarəli ikən geri
    açmaq olmur (admin üçün də); aydın xəta mesajı ilə. Aylıq dövr və avtomatlaşdırma təsirlənmir.
  - **Gecikmə rəngi olan sahələr**: gecikən tapşırığın cədvəldə adı və bu xanaları gecikmə gününə görə rənglənir.
