## Nə yenidir

- **Workspace üzrə SMTP ayarları (ADR-0038):** Ayarlar → **Email** (yalnız admin). Host, port, şifrələmə
  (STARTTLS/SSL), istifadəçi adı, parol, From və Reply-To; Gmail/Google Workspace, Microsoft 365 və cPanel üçün hazır
  doldurma; sınaq məktubu (özünüzə və ya workspace üzvünə). Ayar yoxdursa və ya söndürülübsə, server konfiqurasiyası
  (`NEBULA_SMTP_*`) əvvəlki kimi işləyir.
- **Təhlükəsizlik:**
  - parol şifrələnmiş saxlanır və API heç vaxt qaytarmır;
  - server, port, şifrələmə və ya istifadəçi adı dəyişəndə parol yenidən daxil edilməlidir (saxlanmış parol başqa
    serverə yönəldilə bilmir);
  - SSRF qoruması saxlananda və hər bağlantıda (DNS rebinding daxil);
  - portlar `25, 465, 587, 2525`; productionda şifrəsiz SMTP və daxili ünvanlar qadağandır;
  - sınaq göndərişləri workspace başına 10 dəqiqədə 5; xətalar təmizlənmiş göstərilir (IP və sirlər yox);
  - dəyişikliklər audit log-a yazılır (parol yox).
