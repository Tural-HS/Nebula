# Nebula v0.1.0

İlk production buraxılışı. Hədəf: tək Linux serverdə Docker Compose (ADR-0015), ilk müştəri — maliyyə
və back-office komandaları (FinTez).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır (düzəldilə bilən
HIGH/CRITICAL zəiflik buraxılışı dayandırır), cosign ilə imzalayır və provenance əlavə edir. Tag yalnız
yoxlanmış və imzalanmış digest-ə qoyulur. Digest-lər iş axınının "Summary" bölməsindədir; `.env`-ə
**digest ilə** yazın (`deploy/production/README.md` §2.3):

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.1.0@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.1.0@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.1.0@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.1.0@sha256:…` |

İmzanın yoxlanması: `deploy.sh … --verify` (cosign keyless, bu repozitoriyanın release iş axını).

## Nə var

- **Əsas:** workspace-lər, layihələr (gizli layihələr), tapşırıq tipləri, workflow-lar və status keçidləri,
  fərdi sahələr, avtomatlaşdırma, webhook-lar və email, şərhlər, @mention, aktivlik, audit log
  (ADR-0001–0007, 0013).
- **Görünüşlər:** cədvəl, lövhə, təqvim; saxlanılan görünüşlər, cəm sətri, toplu və sətirdaxili redaktə,
  workspace üzrə axtarış (ADR-0014, 0023, 0024).
- **Əməkdaşlıq:** dəvətlər, tətbiqdaxili bildirişlər, alt tapşırıqlar, fayl əlavələri və Markdown,
  əlaqələr və izləyicilər (ADR-0016, 0017, 0021, 0022, 0028).
- **Maliyyə əməliyyatları:** "dörd göz" təsdiqi, iş təqvimi (Azərbaycanın 2026 rəsmi təqvimi daxil),
  formul sahələri, imzalı audit sübut paketi, qəbul formaları və "Tələblərim", Mattermost/Slack təsdiq
  kartları, təkrarlanan tapşırıqlar və gecikmə xülasəsi (ADR-0009, 0012, 0026, 0027, 0029–0032).
- **Keçid:** CSV/xlsx və Mattermost Boards (`.boardarchive`) importu, azərbaycanca workspace şablonu,
  layihə şablonları (ADR-0011, 0020; runbook `docs/runbooks/mattermost-boards-migration.md`).
- **İnterfeys:** azərbaycanca, ingiliscə, türkcə, rusca; telefon və planşet (ADR-0019, 0025).

## Quraşdırma

`deploy/production/README.md` §1–§5 ardıcıllığı ilə: host hardening → `gen-secrets.sh` → image digest-ləri
→ baza və backup → ilk deploy → Keycloak admini → **real məlumatdan əvvəl** backup və restore testi.

Tələb olunan sirlər `gen-secrets.sh` ilə yaradılır; xarici sirləri (S3, SMTP) admin özü fayla yazır.
v0.1.0-da yeni: `nebula_evidence_signing_key` (ADR-0029).

## Məlum məhdudiyyətlər

- Serverin göndərdiyi mətnlər (dəvət emaili, chat mesajları, gecikmə xülasəsi) azərbaycancadır (ADR-0025).
- Caddy `x/net` istisnası (CVE-2026-78661) 2026-12-31-ə qədər; plan ADR-0018-dədir.
- Anonim (girişsiz) formalar yoxdur (ADR-0032); chat-dan birbaşa təsdiq ikinci mərhələdir (ADR-0031).
- ghcr paketləri ilk dəfə **private** yaranır: serverin image-ləri çəkə bilməsi üçün paketləri public edin
  və ya serverdə yalnız `read:packages` hüquqlu token ilə `docker login ghcr.io` edin.
