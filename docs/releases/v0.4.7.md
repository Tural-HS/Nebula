# Nebula v0.4.7

Ada görə sıralama (ADR-0063) və cədvəlin üstündə xülasə zolağı (ADR-0064).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.4.7@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.4.7@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.4.7@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.4.7@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- Sıralama menyusunda **"Ada görə (A–Z)"** və **"(Z–A)"**: Azərbaycan əlifbası ilə (C, Ç, …, E, Ə, …, S, Ş);
  görünüşdə saxlanır. API: `sort=title` / `sort=-title`.
- Cədvəlin üstündə **xülasə zolağı**: "📅 Noyabr 2026 hesabatı · 💰 Aylıq ödəniş cəmi · 📊 Yığılası qalıq · 💵 Ödənilib";
  sətirlər layihə ayarlarında seçilir (sahənin cəmi, istəyə görə başqa sahənin cəmi çıxılmaqla), filtrlərə uyğun
  və canlı.
