# Nebula v0.4.6

Kiçik buraxılış: avtomatlaşdırmanın "Sahəni doldur" əməliyyatı dəyəri başqa sahədən götürə bilir (ADR-0062).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.4.6@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.4.6@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.4.6@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.4.6@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- "Sahəni doldur" əməliyyatında **"Dəyər mənbəyi"**: sabit dəyər və ya tapşırığın başqa sahəsi (məs. Qalıq =
  Aylıq ödəniş).

## Miqrasiyalar

Yoxdur.

## Yeniləmə (v0.4.5 → v0.4.6)

`deploy.sh` yeni digest-lərlə (`--verify`). `.env`-də dəyişiklik lazım deyil. Geri qayıtmaq: v0.4.5 image-ləri
(köhnə image `from` ilə qaydanı sabit dəyərsiz kimi rədd edir — əvvəl həmin qaydanı söndürün).
