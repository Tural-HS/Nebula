# Nebula v0.3.3

v0.3.2-dən sonrakı buraxılış: rənglər və cədvəl sıxlığı (ADR-0047).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.3@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.3@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.3@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.3@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.
