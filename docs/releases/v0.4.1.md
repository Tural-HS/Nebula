# Nebula v0.4.1

v0.4.0-dan sonrakı kiçik buraxılış: "Sahələri başqa layihəyə köçür" əməliyyatı hədəf tapşırığı yoxdursa yarada bilir.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.4.1@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.4.1@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.4.1@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.4.1@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- `copy_fields` əməliyyatında **"Hədəfdə yoxdursa, yarat"** seçimi (`create: true`, ADR-0056): uyğunlaşdırma
  dəyəri (məs. NV nömrəsi) olan, amma hədəf layihədə tapılmayan mənbə üçün eyni ad və sahələrlə yeni tapşırıq
  yaradılır. Sonrakı dəyişikliklər həmin tapşırığı yeniləyir; ikinci nüsxə yaranmır.

## Miqrasiyalar

Yoxdur.

## Yeniləmə (v0.4.0 → v0.4.1)

`deploy.sh` yeni digest-lərlə (`--verify`). `.env`-də dəyişiklik lazım deyil. Geri qayıtmaq: v0.4.0 image-ləri
(köhnə image `create` sahəsini nəzərə almır, sadəcə yeniləyir).
