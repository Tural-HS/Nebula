# Nebula v0.2.0

v0.1.0-dan sonrakı buraxılış: yeni dizayn, komanda şablonları, təsdiq təkmilləşdirmələri, brendli giriş
səhifəsi və FinTez pilotu üçün paylaşılan hostda quraşdırma (pulsuz yerli backup ilə).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. Digest-lər iş axınının "Summary" bölməsindədir; `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.2.0@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.2.0@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.2.0@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.2.0@sha256:…` |

Paketlər public-dir; serverdə `docker login` lazım deyil. Image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Dizayn (ADR-0035):** "Ledger" cədvəli və tapşırıq paneli, sayğac zolağı (gecikmiş, təsdiq gözləyən,
  bloklanmış…), status addımları, açıq/qaranlıq/sistem mövzusu, workspace üçün 7 seçilmiş vurğu rəngi.
- **Komanda şablonları (ADR-0033):** yeni workspace Maliyyə, IT və ya HR şablonu ilə yaradılır (statuslar,
  sahələr, ƏDV düsturu, "dörd göz" siyasəti, rəsmi təqvim, görünüşlər, forma).
- **Təsdiq (ADR-0034):** workspace üzrə "Təsdiqimi gözləyənlər" siyahısı və nişanı, təsdiqdən sonra izlənən
  sahə dəyişəndə yenidən təsdiq, iş günləri ilə müddət və xatırlatma.
- **Layihənin standart görünüşü (ADR-0014 əlavəsi):** layihə seçilmiş ümumi görünüşlə açılır; şablonlar
  "Bütün tapşırıqlar" görünüşünü (məbləğ və s. sütunlarla) standart edir.
- **Telefon:** siqnallar açar sətrində (son tarix, təsdiq, bloklanma), ayrıca sütun yoxdur.
- **Giriş səhifəsi (ADR-0036):** Nebula loqosu, qradiyent marka paneli, 4 dildə şüar, açıq/qaranlıq mövzu.
  Mövcud realm üçün bir dəfə: `deploy/production/README.md` §3 ("Giriş səhifəsinin mövzusu").
- **Paylaşılan hostda pilot (README §13):** Nebula artıq 80/443-ü tutan başqa stack-in Caddy-si arxasında
  (`compose.shared-host.yaml`), həmin stack-in compose faylı dəyişmir.
- **Pulsuz yerli backup (README §13.5):** eyni hostda S3 uyğun hədəf (`compose.local-s3.yaml`), TLS
  yoxlaması ilə; sonradan off-site S3-ə `repo2` ilə itkisiz keçid.

## Düzəlişlər

- Axtarış qutusu URL-i dərhal yazır: görünüş yadda saxlananda köhnə axtarış mətni qalmırdı ("dəyişdirilib" ilişirdi).
- 25 MB-dan böyük Mattermost Boards arxivləri Caddy-də rədd edilirdi; import marşrutları üçün limit 53 MB.
- Postgres S3 əlçatmaz olanda yenidən başlamırdı (`init: true`, v0.1.0-dan sonrakı prova düzəlişi).
- Cədvəldə redaktə olunan rəqəm xanaları sağa düzlənir; planşetdə başlıq daşması düzəldi.
