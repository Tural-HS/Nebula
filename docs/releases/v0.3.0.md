# Nebula v0.3.0

v0.2.2-dən sonrakı buraxılış: layihə və workspace-lərin arxivlənməsi və silinməsi, Excel/CSV ixracı,
hesabatlar, məzuniyyət zamanı təsdiq əvəzləməsi, inteqrasiyalar üçün API tokenləri, valyuta sahəsi və iş günü
ilə SLA. Altı yeni miqrasiya (00031–00036) var: yeniləmədən **əvvəl** backup alın.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.0@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.0@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.0@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.0@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Arxivləmə və silmə (ADR-0039):** layihə və workspace arxivlənir (yalnız oxunur) və bərpa olunur. Həmişəlik
  silmə yalnız sahibə açıqdır, yalnız arxivlənmiş obyektə, adı yazmaqla təsdiqlənir və fonda icra olunur;
  silmədən əvvəl sübut paketini yükləmək təklif olunur. Silinmiş workspace-lərin qeydi saxlanılır.
- **Excel/CSV ixracı (ADR-0040):** tapşırıq cədvəli göründüyü kimi (filtrlər, sütunlar, sıralama) ixrac olunur;
  rəqəm və tarixlər əsl Excel xanalarıdır, formula injection-a qarşı qorunur, 50 000 sətir limiti, audit qeydi.
- **Hesabatlar (ADR-0041):** workspace üzrə KPI-lar, yaradılan/tamamlanan, gecikmənin yaşı, təsdiq müddəti
  (median, p90), icraçılar üzrə yük (CSV ilə) və layihələr üzrə status bölgüsü.
- **Məzuniyyət və əvəzləmə (ADR-0042):** təsdiqçi məzuniyyətdə olanda təyin etdiyi əvəzləyən onun adına qərar
  verir; qərarda kimin adına verildiyi görünür, "dörd göz" qaydası bazada qorunur.
- **API tokenləri (ADR-0043):** 1C, bank və BI inteqrasiyaları üçün workspace tokenləri: scope-lar, layihə
  siyahısı, son istifadə vaxtı, ləğv etmə; token yalnız bir dəfə göstərilir, bazada hash saxlanılır, ayrıca
  sürət limiti var.
- **Valyuta sahəsi (ADR-0044):** AZN/USD/EUR məbləğləri; cəmlər hər valyuta üçün ayrıca, valyutalar qarışmır.
- **SLA (ADR-0045):** layihə üzrə iş günü ilə cavab və həll hədəfləri, "SLA pozulub" və "SLA riski" filtrləri,
  risk və pozulma bildirişləri.
- **Boards importu:** 1970-dən əvvəlki tarixlər artıq itmir.
- **Düzəliş:** workspace-dən kənar səhifələrdə lazımsız 404 sorğusu aradan qaldırıldı.

## Təhlükəsizlik

Yeni funksiyalar buraxılışdan əvvəl ayrıca review-dan keçib; tapıntılar düzəldilib:
- layihə ilə məhdudlaşdırılmış token, həmin layihə silinəndə bütün workspace-ə çıxış qazanırdı: indi məhdudiyyət
  bazada saxlanılır (00036), siyahısı boşalan token ləğv olunur;
- əlaqə etiketləri gizli layihələrin tapşırıq adlarını göstərmir;
- workspace silinəndə onun token istifadəçiləri deaktiv olunur;
- rollback (`goose down`) mümkün olmayan hallarda aydın xəta ilə dayanır.

## Yeniləmə (v0.2.x → v0.3.0)

1. `deploy.sh` yeni digest-lərlə (`--verify`): imzaları yoxlayır, miqrasiyadan əvvəl incremental backup alır,
   miqrasiyaları ayrıca addımda işlədir, sonra konteynerləri dəyişir; uğursuzluqda image-ləri geri qaytarır.
2. `--skip-backup` istifadə etməyin: bu buraxılışda sxem dəyişir.
3. `.env`-də dəyişiklik məcburi deyil. İstəyə görə: `NEBULA_RATE_LIMIT_TOKEN_RPS` (default 5) və
   `NEBULA_RATE_LIMIT_TOKEN_BURST` (default 20) — API tokenləri üçün limit.

## Məlum məhdudiyyətlər

- Valyuta məzənnəsi yoxdur: cəmlər valyutalar arasında çevrilmir.
- SLA hədəfi layihə üzrədir, tapşırıq növünə görə ayrıca hədəf yoxdur; hesabatlarda SLA KPI-ı hələ yoxdur.
- API tokeni yenilənmir (rotate): yenisini yaradıb köhnəni ləğv edin.
- Caddy `x/net` istisnası 2026-12-31-ə qədər (ADR-0018).
