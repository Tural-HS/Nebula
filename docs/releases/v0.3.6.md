# Nebula v0.3.6

v0.3.5-dən sonrakı buraxılış: aylıq dövr (ADR-0051), səhər xülasəsində "bu gün son tarix", şəxsi qeydlər
(ADR-0052), FinTez yaşıl teması və bir neçə düzəliş.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.6@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.6@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.6@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.6@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Aylıq dövr** (layihə → "Aylıq dövr"): seçilmiş gündə hər ay keçən ayın snapshot-ı yazılır (Nebula-da cədvəl
  kimi, cəmlərlə oxunur), sonra aylıq işarələr silinir və sahələr yenidən doldurulur (məs. "Ödədi" silinir, Qalıq ←
  Aylıq ödəniş). Seçimlər: bağlı tapşırıqları da sıfırlamaq, statusu qaytarmaq (məs. "Görüləcək"). Admin üçün
  önizləmə və "İndi bağla". Hər ay bir dəfə; hər dəyişiklik adi `item.updated` (Aktivlik, webhook).
- **Səhər xülasəsi:** gecikənlərdən əlavə "📅 Bu gün son tarix" siyahısı; layihəyə bağlı webhook yalnız öz
  layihələrini alır (hər şöbənin kanalı). Mattermost/Slack webhook-unun standart hadisələrinə
  `workspace.overdue_digest` əlavə olundu.
- **Qeydlərim:** ana səhifədə şəxsi sticky note-lar (5 rəng, sancaq, redaktə, "Geri qaytar" ilə silmə); yalnız
  müəllif görür.
- **Yaşıl tema** (FinTez rəngləri): açıq fon, yaşıl brend şkalası, WCAG AA.
- **Telefonlar:** kodsuz saxlanmış Azərbaycan nömrələri (`515614145`, `0515614145`) indi `+994` ilə yığılır
  (əvvəl telefondan zəng heç kimə getmirdi) və "+994 51 561 41 45" kimi göstərilir.
- **Toplu redaktədə "Geri qaytar"**: hər tapşırıq öz əvvəlki dəyərinə qayıdır.
- **Cədvəldə ↑/↓** ilə sətirlər arasında keçid, Enter ilə açmaq.

## Miqrasiyalar

- `00037_period_cycles`: `period_cycles`, `period_closes`, `period_snapshots` (yeni cədvəllər, kilid yoxdur).
- `00038_user_notes`: `user_notes` (yeni cədvəl).

## Yeniləmə (v0.3.5 → v0.3.6)

`deploy.sh` yeni digest-lərlə (`--verify`): pre-deploy backup, sonra miqrasiyalar. `.env`-də dəyişiklik lazım
deyil. Geri qayıtmaq (v0.3.5 image-ləri) mümkündür: yeni cədvəllər köhnə versiya tərəfindən istifadə olunmur.
