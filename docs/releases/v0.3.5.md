# Nebula v0.3.5

v0.3.4-dən sonrakı buraxılış: yeni temalar, zəng nəticələri və tez əməliyyatlar (ADR-0049, ADR-0050).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.5@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.5@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.5@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.5@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Temalar:** Açıq və Tünd-dən əlavə Kağız, Gecə göyü və Yüksək kontrast (cəmi 5). Hamısı WCAG AA kontrastından
  keçir; seçim ilk çəkilişdən əvvəl tətbiq olunur (ADR-0049).
- **Bəli/xeyr bir kliklə:** cədvəldə xanaya klik dəyəri dəyişir, 8 saniyəlik "Geri qaytar" bildirişi görünür.
- **Zəng nəticəsi:** paneldə "Cavab verdi / Cavab vermədi / Söz verdi (tarix) / Yanlış nömrə". Hər biri şərh
  kimi yazılır; "Söz verdi" son tarixi həmin günə keçirir. Telefon sahəsi olan layihələrdə görünür.
- **Növbəti/əvvəlki tapşırıq:** paneldə "← n / ümumi →" və J/K düymələri.
- **Telefonda cədvəl:** hər adın altında telefon (toxunanda zəng), Aylıq ödəniş və Qalıq.
- **Layihə keçidi:** başlıqdakı layihə adından siyahı açılır.
- **Filtrlər:** "Boş olanlar / Dolu olanlar"; seçim sahələrində bir neçə dəyər üzrə filtr.
  API: `?field.<key>=is:empty`, `is:set`, `in:id1,id2` (ən çox 20).
- **Hesabat:** bir layihə seçiləndə açıq və bağlanmış tapşırıqlar üzrə məbləğ sahələrinin cəmi.
- **Digər:** ₼/AZN məbləğləri 2 onluqla; brauzerin `confirm` pəncərəsi əvəzinə tətbiqin öz dialoqu; "Sil"
  panelin "⋯" menyusunda; "Məzmuna keç" linki; hesabatda idxal olunmuş bağlı tapşırıqlar haqqında izah.

filtrli saxlanmış görünüşlər boş siyahı göstərə bilər.
