# Nebula v0.3.1

v0.3.0-dan sonrakı kiçik buraxılış: çox sütunlu cədvəllərin (məsələn, Boards-dan idxal olunmuş reyestrlərin) oxunaqlığı.

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.1@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.1@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.1@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.1@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Sabit başlıq:** kompüterdə cədvəl sağa sürüşdürüləndə açar (#) və başlıq yerində qalır; telefonda başlıq
  əvvəlki kimi sabitdir.
- **Siqnal sütunu:** heç bir sətirdə siqnal (təsdiq, alt tapşırıq, bloklama, SLA) yoxdursa, sütun göstərilmir.
- **Dar sütunlar:** bəli/xeyr sahələri 6 rem, mətn sahələri 10 rem.
- **Uzun başlıqlar** sütunun içində "…" ilə qısalır (əvvəl qonşu sütunun üstünə düşürdü); tam mətn siçanı
  üstünə gətirəndə görünür.
