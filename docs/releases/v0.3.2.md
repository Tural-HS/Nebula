# Nebula v0.3.2

v0.3.1-dən sonrakı buraxılış: reyestr qeydləri (Boards-dan idxal olunmuş müştəri kartları) üçün interfeys (ADR-0047).

## Image-lər

Release iş axını (`.github/workflows/release.yml`) dörd image qurur, Trivy ilə yoxlayır, cosign ilə imzalayır
və provenance əlavə edir. `.env`-ə **digest ilə** yazın:

| Dəyişən | Image |
|---|---|
| `NEBULA_IMAGE` | `ghcr.io/tural-hs/nebula:v0.3.2@sha256:…` |
| `NEBULA_WEB_IMAGE` | `ghcr.io/tural-hs/nebula-web:v0.3.2@sha256:…` |
| `POSTGRES_IMAGE` | `ghcr.io/tural-hs/nebula-postgres:v0.3.2@sha256:…` |
| `KEYCLOAK_IMAGE` | `ghcr.io/tural-hs/nebula-keycloak:v0.3.2@sha256:…` |

Paketlər public-dir; image-lər yalnız `linux/amd64` üçündür.

## Nə yenidir

- **Əsas məlumat kartı:** tapşırıq panelində başlığın altında doldurulmuş sahələr böyük şriftlə (telefonda birinci,
  kompüterdə tam en); redaktə sağdakı sahə siyahısındadır.
- **Boş bölmələr** (təsvir, alt tapşırıq, əlaqə, fayl) bir "Əlavə et: + …" sətrinə yığılır; klik bölməni açır.
- **Rəqəm vahidi:** Ayarlar → Sahələr-də rəqəm sahəsinə vahid (₼, AZN, %, …, 8 simvola qədər); hüceyrədə, Cəmi sətrində
  və paneldə "1 315 ₼".
- **Telefon linkləri:** telefon sahələrində (adı/açarı telefon, 7–15 rəqəm) nömrəyə toxunanda zəng; paneldə həmişə,
  cədvəldə toxunma ekranında və oxuma hüququnda.
- **Ad sütunu** daha enli (18 rem).

## Miqrasiyalar

Yeni miqrasiya yoxdur (`field_definitions.options` artıq `jsonb`-dir).

göstərilmir; dəyərlər dəyişmir.
