# ADR-0029: Audit sübut paketinin ixracı

- Status: Qəbul edilib
- Tarix: 2026-11-24

## Kontekst

Auditor və tənzimləyici (FinTez üçün — Mərkəzi Bank yoxlaması, xarici audit) eyni sualı verir: **"bunu kim yaratdı,
kim dəyişdi, kim təsdiqlədi və nə vaxt?"** Cavab Nebula-dadır: hadisə jurnalı (`events`, ADR-0007), təsdiq sorğuları
və qərarları (ADR-0026), şərhlər, əlaqələr (ADR-0028), faylların SHA-256-sı (ADR-0022). Amma indiyədək onu yalnız
ekrandan göstərmək və ya skrinşot vermək olardı: auditor üçün nə tam, nə də yoxlanıla bilən deyil.

Lazım olan: admin bir düymə ilə **öz-özünə kifayət edən, yoxlanıla bilən** paket ixrac edir — bir tapşırıq üçün və ya
layihə(lər) + tarix aralığı üçün; auditor paketi Nebula-ya girişi olmadan oxuyur və dəyişdirilmədiyini yoxlayır.

## Nəticələr

- **Miqrasiya yoxdur** (00022 nömrəsi istifadə edilmədi). Rollback: yalnız image; köhnə image
  `NEBULA_EVIDENCE_SIGNING_KEY_FILE`-ı tanımır və nəzərə almır, `evidence.exported` hadisələri jurnalda qalır
  (köhnə UI onları ümumi hadisə kimi göstərir).
- Yeniləmə: `sudo ./scripts/gen-secrets.sh` yeni `nebula_evidence_signing_key` faylını yaradır (mövcud fayllara
  toxunmur); `preflight.sh` faylsız deploy-u dayandırır. Fayl offline nüsxəyə yazılmalıdır.
- Açar rotasiyası: yeni seed → yeni barmaq izi. Köhnə paketlər öz açıq açarını daşıdığı üçün yoxlanmağa davam edir
  (`--key <köhnə barmaq izi>`); auditorlara yeni barmaq izi ayrıca kanalla bildirilməlidir.
- Paket ixrac edənin rolunu və emailini daşıyır: bu, auditin bir hissəsidir (kim ixrac etdi).
- Hash zənciri olmadan jurnalın bütövlüyü **ixraclar arası** sübut olunur: iki ixrac arasındakı silmə/redaktə
  `verify --against` ilə görünür; heç vaxt ixrac edilməmiş dövr üçün sübut yoxdur. Bu, tək-host modelinin (ADR-0015)
  real sərhədidir.
- Testlər: `internal/evidence` (imza, dəyişdirilmiş fayl, dəyişdirilmiş və yenidən imzalanmış manifest, çatışmayan və
  artıq fayl, `../` adı, digest, müqayisə, əhatə, escape, CSV injection, 100 MB limiti),
  `cmd/nebula/evidence_test.go` (çıxış kodları, `--key`, `--against`), `internal/server/evidence_integration_test.go`
  (rollar, məxfilik, `approvals_only`, layihə filtri, limitlər, rate limit, hadisə, söndürülmüş ixrac).
  Web: `lib/evidence.test.ts`. E2E: `web/e2e/evidence.spec.ts`.

## Açıq suallar

- **Xarici lövbər:** hər gün `events`-in son id-si və digest-ini imzalayıb kənara (email, RFC 3161 vaxt möhürü
  xidməti, S3 Object Lock) göndərmək — ixrac edilməmiş dövrlər üçün də silmə sübutu. Ayrıca ADR.
- Read-only **auditor rolu** (Nebula-ya birbaşa giriş) tələb olunarsa — rol modelinin genişlənməsi.
- Limitlərdən böyük ixrac (illik, bütün workspace) lazım olsa — fon job-u və müddətli yükləmə.
- Açar rotasiyasında köhnə açıq açarların siyahısını Parametrlərdə göstərmək.
- Faylların özünü (istəyə bağlı, ölçü limiti ilə) paketə daxil etmək.
